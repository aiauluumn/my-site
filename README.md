# My Site

Учебный репозиторий с простой статической веб-страницей (HTML, CSS, JavaScript).
Служит для отработки работы с коммитами, ветками и тегами в Git.

## Настройка разработки

1. Клонировать репозиторий и перейти в каталог проекта.
2. Открыть `index.html` в браузере (сборка не требуется).
3. Редактировать файлы в VS Code или другом редакторе.
4. Работать по схеме веток: `main` <- `develop` <- `feature/<название>`.
5. Сообщения коммитов оформлять в формате `<type>: <summary>`.
